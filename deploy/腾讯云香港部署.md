# 腾讯云香港轻量服务器部署

适用于首轮 50–200 人/日验证：Ubuntu 24.04 LTS、2 核 4 GB、70 GB SSD，一台服务器同时运行 Caddy、静态页面、Node API 和 SQLite。简历正文仍只在请求内存中处理；SQLite 只保存邀请码摘要、会话摘要、同意记录、次数和估算费用。PDF/DOCX 由短生命周期子进程解析，systemd 对主进程和所有子进程共同设置 768 MB 内存上限。

## 目录

- 程序：`/opt/resume-app/current`
- 运行配置：`/etc/resume-app.env`
- 邀请码数据库：`/var/lib/resume-app/app.db`
- Caddy 配置：`/etc/caddy/Caddyfile`

## 运行配置

在 `/etc/resume-app.env` 中配置以下内容。两个密钥分别生成，至少 32 个字符，不要发送到聊天或提交到 Git。

```dotenv
PORT=8787
ACCESS_REQUIRED=true
ACCESS_DB_PATH=/var/lib/resume-app/app.db
INVITE_PEPPER=替换为独立随机密钥
SESSION_HMAC_SECRET=替换为另一个独立随机密钥

ACCESS_SESSION_DAYS=14
INVITE_DAILY_FLOW_LIMIT=2
INVITE_TOTAL_FLOW_LIMIT=20
DAILY_EXTERNAL_ALERT_YUAN=5
DAILY_EXTERNAL_BUDGET_YUAN=10
EXTERNAL_REQUEST_COST_MICROS=9670
WRITE_REQUESTS_PER_HOUR=30
REDEEM_REQUESTS_PER_15_MINUTES=10

AI_PROVIDERS=deepseek
AI_TIMEOUT_MS=120000
DEEPSEEK_API_KEY=替换为实际密钥
DEEPSEEK_MODEL=替换为实际模型
```

可以在服务器上分别执行两次以下命令生成密钥：

```sh
openssl rand -base64 48
```

配置文件权限设为仅 root 可读：

```sh
sudo chown root:root /etc/resume-app.env
sudo chmod 600 /etc/resume-app.env
```

## 启动方式

服务器使用 Node.js 24。构建完成后，把 `deploy/resume-app.service` 复制为 `/etc/systemd/system/resume-app.service`，再执行：

```sh
sudo useradd --system --home /var/lib/resume-app --shell /usr/sbin/nologin resumeapp
sudo mkdir -p /var/lib/resume-app
sudo chown resumeapp:resumeapp /var/lib/resume-app
sudo systemctl daemon-reload
sudo systemctl enable --now resume-app
sudo systemctl status resume-app
```

把 `deploy/Caddyfile.example` 中的 `resume.example.com` 替换为实际域名，复制到 `/etc/caddy/Caddyfile`。域名解析到服务器公网 IP 后，Caddy 会自动申请 HTTPS 证书。

## 生成邀请码

在程序目录执行：

```sh
sudo -u resumeapp node --env-file=/etc/resume-app.env scripts/create-invite-code.mjs --count=10
```

可选参数：

- `--expires-days=30`：邀请码兑换前的有效天数。
- `--daily-flows=2`：每天完整优化次数。
- `--total-flows=20`：该邀请码可用的完整优化总次数。

明文邀请码只在生成时显示一次。数据库只保存不可逆摘要；同一个码首次兑换成功后不能再次兑换。

需要停止某位体验者继续使用时，执行：

```sh
sudo -u resumeapp node --env-file=/etc/resume-app.env scripts/revoke-invite-code.mjs --code=OFFER-XXXX-XXXX-XXXX
```

撤销会同时终止该邀请码已经创建的会话。

## 备份与更新

每日备份 `/var/lib/resume-app/app.db` 及同目录的 `-wal`、`-shm` 文件，或先短暂停止应用再复制数据库。备份包含邀请码和使用统计，不包含简历正文。

每次更新使用同一流程：拉取已确认版本、`npm ci`、`npm run build`，然后执行：

```sh
sudo systemctl restart resume-app
sudo systemctl reload caddy
```

回滚时把 `/opt/resume-app/current` 指回上一个已构建版本并重启 `resume-app`。不要使用 Vite 开发服务器承载公网流量。
