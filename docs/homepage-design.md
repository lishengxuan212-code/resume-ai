# 首页视觉与动效定稿

依据：用户在本轮确认的黑色 OFFER 首页示意图（selected-homepage.png）及首次开发边界。

- 纯黑背景、居中艺术宋体标题、银白磨砂 OFFER 信封，不使用月亮或霓虹字。
- 标题：心仪的工作，从好简历开始。
- 副文案：针对目标岗位优化简历，让你的优势更有说服力。
- 一个磨砂上传面板，另设在线填写入口；首次体验免注册，不显示流程图。
- OFFER 每 4 秒完成一次上下往返，范围 -6px 到 6px，自然缓入缓出，亮度轻微变化。文字与操作区域静止。减少动态效果偏好下关闭动画。
- 电脑为主，手机端单列自适应；正文可读，按钮可触达。
- 本轮仅实现首页与入口交互预览：本地文件选择/拖放、经历填写与核对弹窗。无 AI、登录、上传到服务器、长期保存、简历生成或 PDF 导出；不伪装成已经完成这些能力。
- 暂用 PDF/DOCX、10MB 作为前端文件选择限制；仅验证文件名和大小，不代表已经解析内容。

## 实现任务

1. src/App.jsx：首页、文件选择反馈、填写与核对弹窗；src/Modal.jsx：可关闭、键盘可用的原生对话框。
2. src/styles.css：黑白视觉、Noto Serif SC 标题、布局断点与呼吸动画。
3. src/intake.js：文件选择校验；tests/intake.test.mjs：空文件、类型和大小边界。
4. 浏览器核对桌面和窄屏，验证两个入口、弹窗关闭、事实内容保留；检查控制台；运行 build 并保存截图和 QA。
